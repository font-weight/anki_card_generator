# English Reader for Anki

> Сборка-кандидат, не финальный релиз. Последние исправления прошли локальные проверки, но их повторная проверка в Windows прервана лимитом Codex. Подтверждённые результаты предыдущего R4 и непроверенные этапы раздельно перечислены в TEST_REPORT. Начинайте с отдельного тестового профиля Anki.

Chrome-расширение: чтение английского → слово под курсором или выделение до пяти слов → **Shift** → контекстный перевод → одно выбранное значение → Anki.

**Статус проверок:** см. [TEST_REPORT](docs/TEST_REPORT.md). Модульные тесты не являются проверкой настоящего Windows Chrome, платного OpenAI или реального Anki. Не используйте личную коллекцию для первого теста.

## Установка в Windows 10/11

1. Распакуйте `dist/english-reader.zip` в постоянную папку. Не перемещайте её, пока расширение установлено.
2. Откройте `chrome://extensions`, включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите каталог `dist/english-reader/` **с файлом `manifest.json`**, не ZIP и не родительскую папку.
4. Закрепите расширение на панели Chrome. Для чтения сайта разрешайте доступ только к нужному сайту по действию пользователя. Системные страницы Chrome и встроенный PDF viewer недоступны для обычного внедрения.
5. После обновления файлов нажмите «Обновить» у расширения и перезагрузите читаемую вкладку.

Цель поддержки — текущий и предыдущий Chrome Stable; minimum Chrome 120 не означает, что все версии с 120 проверены.

## Anki и AnkiConnect

1. Установите desktop Anki. Для первого запуска создайте отдельный **тестовый профиль** без личных карточек.
2. Установите [AnkiConnect из AnkiWeb](https://ankiweb.net/shared/info/2055492159): в Anki откройте дополнения, добавление по коду `2055492159`, затем перезапустите Anki. Официальный [репозиторий проекта](https://github.com/FooSoft/anki-connect) сообщает о переносе разработки в SourceHut; используйте официальную карточку дополнения, не случайные сборки.
3. Оставьте Anki запущенным. В настройках расширения выполните проверку соединения. AnkiConnect должен слушать только локальный loopback, а не `0.0.0.0`/публичную сеть.
4. Если AnkiConnect просит разрешить доступ, сверяйте точный origin `chrome-extension://<ID>`, где ID показан в `chrome://extensions`. Не разрешайте все сайты через `*`.
5. Выберите колоду. `English::Reading` — предлагаемое имя, а не разрешение создавать её молча; при необходимости создайте её сами в тестовом профиле.
6. Явно согласитесь на создание **EnglishReader.Recognition.v1** и **EnglishReader.Cloze.v1**. Если модель с таким именем уже есть, но её поля/шаблоны несовместимы, расширение не должно переписывать её автоматически.

Один выбранный тип создаёт одну карточку, без автоматической reverse-карточки и без изменения расписания повторений.

## Ключ и оплата OpenAI

Откройте доверенные настройки расширения, введите свой API-ключ. **OpenAI API оплачивается отдельно от ChatGPT**. Не вставляйте ключ на читаемую страницу, в исходники, issue, Slack или screenshot.

По умолчанию ключ хранится только на сессию браузера. Постоянное локальное хранение — отдельный opt-in, не обещание шифрованного хранилища. Основной перевод: `gpt-4.1-mini`; явное уточнение: `gpt-4.1`; cloud audio: `gpt-4o-mini-tts`. Доступность зависит от API-аккаунта; автоматического повышения модели быть не должно.

Включение dictionaryapi.dev для IPA и платного cloud audio требует отдельных согласий. Быстрое системное озвучивание может работать без cloud audio, если в Windows доступен английский голос. Оно не создаёт аудиофайл для Anki.

## Чтение и сохранение

- Наведите курсор на слово или выделите до пяти слов, нажмите Shift. Движение мышью само по себе не запрашивает перевод.
- Выберите **один смысл**, при необходимости отредактируйте один-два перевода этого смысла. Исходное предложение сохраняется; выделенный диапазон относится к исходному тексту.
- IPA с пометкой «сгенерировано ИИ» не является словарной проверкой.
- **Enter** добавляет заметку, если вы не редактируете поле. **Ctrl+Enter** сохраняет из редактирования. **Escape** закрывает окно; отпускание Shift не закрывает. Tab работает как обычная навигация.
- `queued` («Сохранено в очередь») означает, что заметка **ещё не подтверждена в Anki**. `added` означает успешное добавление. Возможный дубль требует решения пользователя; не выбирайте «добавить новую» автоматически.
- При восстановлении Anki откройте очередь и проверьте состояние/повтор. Не создавайте вручную новую операцию только потому, что ответ задержался: исходная могла уже сохраниться.

## PDF, EPUB и локальная библиотека

Откройте библиотеку расширения. Выберите файл или перетащите PDF/EPUB в область импорта. Импорт сохраняет книгу локально в браузере; в облако она не отправляется. При недостатке quota используйте предложенное открытие только на текущую сессию либо освободите место явным удалением ненужной книги.

- **PDF:** нужен текстовый слой. Чтение происходит в собственном PDF.js viewer, не встроенном viewer Chrome. Для скана OCR не поддерживается. Источник заметки содержит 1-based номер страницы; прогресс включает страницу/позицию.
- **EPUB:** EPUB 2/3 reflowable без DRM. Есть главы/оглавление и CFI позиции; постоянных номеров страниц нет. Изменение размера шрифта не должно терять место.
- Ради безопасности скрипты, CSS книги, SVG, формы и встроенные шрифты удаляются. Вид книги может отличаться; не ослабляйте sandbox для восстановления оформления.
- Локальный источник книги может не открыться на другом устройстве. Храните исходные файлы отдельно.

## Диагностика

| Симптом | Что проверить |
|---|---|
| Shift ничего не делает | Доступ к сайту, перезагрузка вкладки; курсор над текстом; не input/contenteditable/IME; не системная страница Chrome |
| OpenAI недоступен | Ключ в настройках, API billing/доступ к модели, сеть; после закрытия браузера session key нужно ввести снова |
| Anki недоступен | Anki запущен, дополнение установлено и перезапущено, правильный тестовый профиль, loopback и разрешение origin |
| В очереди, но нет карточки | Это не сообщение об успешном добавлении; восстановите Anki, прочитайте ошибку, повторите исходную операцию |
| Нет IPA | Словарь выключен/недоступен или нет записи; перевод не обязан блокироваться |
| Нет звука | Системный голос отсутствует; cloud audio не включено; при сохранении аудио проверьте отдельный статус ошибки |
| EPUB отклонён | DRM/fixed-layout, повреждённый XML/ZIP, внешний ресурс или лимиты архива; не снимайте защиту ради файла |

Не отправляйте необработанный HAR: он может содержать Authorization и частный текст.

## Резервирование и очистка

- Делайте резервную копию коллекции средствами Anki, включая media. Браузерная очередь не является backup Anki.
- Храните оригиналы PDF/EPUB вне браузера. Экспорт библиотеки/очереди **не обещается**, если его нет в интерфейсе.
- Обычная очистка кэша не должна удалять книги, прогресс, очередь или медиа для ожидающих операций.
- Удаление книги выполняйте отдельным действием. До uninstall/очистки профиля завершите или осознанно отмените очередь: профильные данные могут быть потеряны.
- Удалите API-ключ через настройки, а для полного отзыва также отзовите его у провайдера.

## Сборка из исходников

Требуется Node, совместимый с `package.json` (Node 24+), и npm. Из корня проекта:

```powershell
npm ci
npm run typecheck
npm test
npm run build
```

Lockfile обязателен; не заменяйте `npm ci` на незакреплённое обновление пакетов. Сборка не публикует расширение в Chrome Web Store. Проверки live OpenAI платные и запускаются только после отдельного opt-in; реальный Anki проверяется только в изолированном тестовом профиле.
