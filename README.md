# Language Reader for Anki

**Читайте на изучаемом языке и превращайте нужные слова и предложения в карточки Anki.**

Language Reader — расширение Chrome Manifest V3 для чтения сайтов, PDF, EPUB и FB2. Оно показывает перевод слова в контексте, помогает выбрать значение, добавляет произношение и примеры по запросу и сохраняет проверенный вами материал в Anki. Для изучения конструкций есть отдельный экспериментальный режим грамматики.

Проект подходит тем, кто учит язык по книгам, статьям и документации и хочет собирать собственную колоду, не перенося каждое предложение вручную.

[Установка](#установка-в-chrome) · [Подключение Anki](#подключение-anki-в-windows) · [English quick start](#english-quick-start)

Версия: **0.7.6**. Интерфейс и это руководство — на русском. Генерация использует ваш OpenAI API-ключ; отправка карточек — локальный Anki Desktop с AnkiConnect. Границы проверок перечислены в [разделе о тестировании](#проверки-и-совместимость).

## Новое в 0.7.6

- **Сведения об английском слове в окне перевода:** ориентировочный уровень CEFR (A1–C2), современное или устаревающее употребление, качественная оценка частоты. Эти сведения помогают решить, стоит ли учить слово сейчас.
- **Метка места чтения:** при нажатии Shift слово под курсором или выделенный фрагмент подсвечивается сразу, даже если перевод ещё загружается или не удался. Метка остаётся после закрытия окна и при прокрутке, пока этот фрагмент есть на странице. Следующий Shift переносит метку. Перезагрузка или закрытие страницы или книги её сбрасывает. Это временная отметка, а не сохранённая закладка Anki или библиотеки.
- Уровень, употребительность и частота показываются **только в окне перевода для английского исходного текста**. Они не добавляются в поля или шаблоны Anki.

Блок помечен **«Оценка ИИ для этого значения»**. Он приходит вместе с обычным ответом перевода, без отдельного запроса. Частота разговорного употребления описывается словами **«очень часто / часто / иногда / редко / нет оценки»**, а уровень — A1–C2 или «нет оценки». Стиль и современность употребления могут различаться: например, слово может быть актуальным, но преимущественно формальным или литературным. Оценки слов даёт модель с учётом значения и контекста. Это **не сертификат CEFR, не измерение по частотному корпусу и не точное число употреблений**. Одно слово может иметь простое частое и редкое специальное значения. Если оценка неизвестна, не стоит подменять её догадкой. Для других исходных языков эти английские характеристики не показываются.

С версии 0.7.5 новые словарные карточки также включают перевод исходного предложения на обороте и подчёркивание выбранного слова или выражения в исходной цитате. Уже созданные карточки автоматически не переписываются.

## Возможности

- **Перевод по Shift.** Слово под курсором или выделенное выражение до пяти лексических сегментов; простое наведение не запускает запрос.
- **17 языков.** Направление перевода задаётся в настройках. Определения даются на языке текста; переводы — на выбранном языке перевода. Возможен одноязычный режим.
- **Слова и выражения.** Несколько значений, начальная форма глагола, английские фразовые глаголы в пределах встроенного набора, редактирование и предпросмотр.
- **Полный перевод предложения.** Новые переводы включают всё показанное исходное предложение; перевод виден на обороте карточки и в предпросмотре. Изучаемое слово или выражение подчёркнуто в оригинале по точному выделенному диапазону, даже если встречается несколько раз. Старые карточки и очередь не переписываются. Если источник содержит только фрагмент, переводится только он — окончание не выдумывается.
- **Карточки Anki.** Узнавание или пропуск `c1`, точная исходная цитата, выбранное значение первым, остальные полученные значения на обороте, источник и необязательное аудио.
- **Локальная библиотека.** PDF, EPUB и обычные FB2; продолжение чтения, оглавление там, где оно доступно, закладки, поиск и настройки оформления.
- **Грамматика.** Одна конструкция и один вопрос по исходному предложению, проверка и ручное добавление в Anki.
- **Очередь словарных карточек.** Сохранённый снимок заметки, видимый статус отправки, проверка возможных дубликатов и неопределённого результата.

## С чего начать

1. [Соберите и установите расширение](#установка-в-chrome).
2. [Подключите OpenAI API](#подключение-openai-и-стоимость).
3. [Подключите Anki и выберите колоду](#подключение-anki-в-windows).
4. Откройте статью, нажмите значок Language Reader → **«Включить чтение»**. Либо откройте **«Библиотеку»** и импортируйте книгу.
5. Наведите курсор на слово и нажмите **Shift**. Проверьте перевод, затем нажмите **«Добавить в Anki»**.

Начните с отдельного тестового профиля Anki и нескольких карточек. Так можно проверить оформление и настройки, не затрагивая основную коллекцию.

### Где находятся основные действия

| Раздел | Для чего нужен |
| --- | --- |
| Меню по значку расширения | Включить чтение в текущей вкладке, открыть библиотеку, настройки или очередь |
| Окно перевода прямо в тексте | Выбрать значение, посмотреть начальную форму, отредактировать, подготовить аудио и сохранить карточку |
| Настройки | API-ключи, языки, колода, типы заметок, разрешения дополнительных функций |
| Библиотека | Открыть и читать локальные книги, продолжить с сохранённого места |
| Очередь Anki | Проверить, какие словарные заметки уже добавлены, а какие требуют внимания |

Открытие меню расширения само по себе не переводит текст и не создаёт карточек. Для сайта чтение включается отдельной кнопкой.

## Установка в Chrome

### Требования

- Настольный **Google Chrome**. В манифесте указан минимум Chrome 120; это технический нижний порог, а не перечень проверенных версий. Для первого запуска используйте актуальный Chrome Stable.
- **Node.js 24 или новее** и npm для сборки. В `.nvmrc` закреплена версия **24.19.0**.
- **Anki Desktop** и **AnkiConnect** для добавления карточек. AnkiWeb и мобильное приложение не заменяют локальное подключение.
- OpenAI API-аккаунт с доступом к используемым моделям и доступным балансом API (купленные или активированные промокредиты) для генерации. Чтение уже импортированной книги и локальный поиск не требуют модельного запроса.

### 1. Соберите из исходников

Скачайте исходники [репозитория](https://github.com/font-weight/anki_card_generator) через **Code → Download ZIP** и распакуйте их либо клонируйте репозиторий. В терминале из корня проекта, где находится `package.json`, выполните:

```sh
npm ci
npm run build
```

Если используете менеджер Node, поддерживающий `.nvmrc`, сначала выберите указанную в нём версию. `npm ci` использует версии из `package-lock.json`; не удаляйте lockfile ради установки.

Результаты обычной сборки:

- `dist/english-reader/` — готовая распакованная папка расширения с `manifest.json`;
- `dist/english-reader.zip` — архив этой папки, который создаёт тот же скрипт сборки.

**ZIP исходников с GitHub не является готовым расширением.** Его сначала нужно собрать. В этом руководстве не предполагается наличие готового GitHub Release или публикации в Chrome Web Store.

### 2. Загрузите расширение

1. Откройте `chrome://extensions`.
2. Включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите `dist/english-reader/`, именно папку с `manifest.json`.
4. Закрепите Language Reader на панели Chrome через меню расширений.
5. Откройте значок расширения → **«Настройки»**.

Если переносите результат сборки на другой компьютер, распакуйте `dist/english-reader.zip` в постоянную папку и выберите вложенную `english-reader/`. Не выбирайте сам ZIP или папку уровнем выше. Не перемещайте установленную папку без необходимости.

Это стандартная [установка распакованного расширения Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked). После обновления сборки требуется перезагрузить расширение и читаемые вкладки.

## Подключение OpenAI и стоимость

### Ключ API

1. Войдите в [OpenAI Platform](https://platform.openai.com/) и создайте API-ключ на [странице ключей](https://platform.openai.com/api-keys).
2. Проверьте баланс API, доступ к моделям и ограничения расходов вашего API-проекта.
3. Откройте **настройки самого расширения**, раздел **«1. Подключение OpenAI»**.
4. Вставьте ключ в **«Ключ OpenAI API»**, нажмите **«Сохранить ключ»**, затем **«Проверить подключение»**.

Ключ вводится только на странице настроек расширения, не в тексте книги, всплывающем окне сайта, issue или чате. По умолчанию он хранится **в текущей сессии браузера**. После завершения сессии или перезагрузки расширения его может потребоваться ввести снова.

Флажок **«Сохранять ключ локально между перезапусками»** — отдельный добровольный выбор. Это не зашифрованный сейф: человек или программа с доступом к профилю браузера могут получить доступ к локальным данным. Для удаления используйте **«Удалить ключ»**; чтобы полностью отозвать доступ, отзовите ключ также в OpenAI Platform.

Проверка подключения не выполняет платный тестовый перевод. Она проверяет доступность модели, но не подтверждает качество ответа или успешную генерацию конкретной карточки.

### Что оплачивается

**У API и ChatGPT отдельный биллинг.** На некоторых платных планах ChatGPT Pro и Business можно [активировать промокредиты API](https://help.openai.com/en/articles/20001626-api-credits-benefit-for-eligible-chatgpt-subscriptions). Если у привязанной API-организации есть активные кредиты и доступ к нужной модели, для запросов расширения используйте ключ проекта этой организации. Добавлять способ оплаты API при действующем гранте не нужно. Проверьте остаток и срок действия в [Credit grants](https://platform.openai.com/settings/organization/billing/credit-grants). Если кредитов нет, см. [тарифы API](https://developers.openai.com/api/docs/pricing).

| Действие | Модель и режим в этой версии |
| --- | --- |
| Контекстный перевод, дополнительные примеры | `gpt-6-luna`, `reasoning.effort: none` |
| «Уточнить смысл — платный запрос» | `gpt-6-luna`, `reasoning.effort: low` |
| Разбор грамматики | `gpt-6-luna`, `reasoning.effort: none` |
| Создание аудиофайла | `gpt-4o-mini-tts`, голос `coral` |

Модели заданы в коде. Автоматической замены недоступной модели другой нет. Доступность зависит от API-аккаунта; описания провайдера: [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [GPT-4o Mini TTS](https://developers.openai.com/api/docs/models/gpt-4o-mini-tts).

Перевод по Shift, уточнение, примеры, грамматика и облачное аудио могут расходовать API-баланс. Совпадающий доступный кэш может избежать нового запроса, но не следует считать каждое повторное действие бесплатным. После сетевого тайм-аута или закрытия окна отправленный запрос уже мог быть обработан и оплачен.

В расширении **нет собственного денежного лимита**. Настройте бюджет и уведомления в OpenAI Platform. Если нужен блокирующий лимит, проверьте, включено ли **Enforce a hard limit**: одно уведомление расходы не останавливает, а применение жёсткого лимита может запаздывать. См. [управление лимитами OpenAI](https://help.openai.com/en/articles/9186755-managing-projects-in-the-api-platform).

Грамматика, dictionaryapi.dev и облачное аудио требуют отдельных разрешений в настройках. Согласие на аудио не создаёт его автоматически: каждый файл запрашивается явным действием в карточке.

## Подключение Anki в Windows

### 1. Установите AnkiConnect

1. Скачайте **Anki Desktop** с [официального сайта Anki](https://apps.ankiweb.net/). Выберите подходящую сборку для вашей Windows.
2. Запустите Anki. Для первого знакомства создайте отдельный тестовый профиль.
3. Откройте **Tools → Add-ons → Get Add-ons** («Инструменты → Дополнения → Получить дополнения»).
4. Введите код **`2055492159`**, соответствующий [AnkiConnect в AnkiWeb](https://ankiweb.net/shared/info/2055492159).
5. Перезапустите Anki и оставьте его открытым во время отправки карточек.

Путь установки дополнений описан в [официальном руководстве Anki](https://docs.ankiweb.net/manual/addons). [Репозиторий AnkiConnect](https://github.com/FooSoft/anki-connect) содержит ссылку на текущую площадку разработки; скачивайте дополнение из официального источника.

### 2. Проверьте локальное подключение

В настройках Language Reader, раздел **«2. Anki и колода»**, оставьте **`127.0.0.1:8765`**. Вариант `localhost:8765` также доступен и внутри транспорта преобразуется в `127.0.0.1`. Произвольные адреса и порты не поддерживаются обычной сборкой. После изменения адреса нажмите **«Сохранить настройки»**.

В конфигурации AnkiConnect сохраняйте локальные значения `webBindAddress: "127.0.0.1"` и `webBindPort: 8765`. Не открывайте порт в интернет и не меняйте адрес на `0.0.0.0` ради подключения расширения.

Если доступ блокируется по origin:

1. Найдите ID установленного Language Reader на `chrome://extensions`.
2. В Anki откройте **Tools → Add-ons → AnkiConnect → Config**.
3. Добавьте в `webCorsOriginList` только точный origin вида `chrome-extension://ВАШ_ID`, сохранив другие необходимые вам записи. Не вставляйте `ВАШ_ID` буквально и не используйте `*`.
4. Сохраните конфигурацию и перезапустите Anki.

Если AnkiConnect показывает запрос разрешения, сверьте этот же origin. Названия параметров и локальные значения можно проверить в [конфигурации AnkiConnect](https://github.com/FooSoft/anki-connect/blob/master/plugin/config.json).

Если в дополнении уже задан `apiKey`, введите **этот отдельный ключ** в разделе **«Ключ AnkiConnect (если настроен в дополнении)»**. Это не OpenAI API-ключ. Его сессионное и постоянное хранение настраиваются независимо.

### 3. Выберите колоду и подготовьте типы заметок

1. Нажмите **«Проверить Anki и получить колоды»**.
2. В поле **«Колода»** выберите существующую колоду. `English::Reading` — предлагаемое имя, а не автоматически созданная колода.
3. Если нужна новая колода, создайте её в Anki либо введите имя и отдельно нажмите **«Создать указанную колоду (явное действие)»**.
4. Выберите тип по умолчанию: **«Узнавание»** или **«Пропуск (c1)»**.
5. Поставьте флажок согласия на создание `LanguageReader.Recognition.v2` и `LanguageReader.Cloze.v2`, затем нажмите **«Создать собственные типы заметок»**.
6. Нажмите **«Сохранить настройки»**.

Расширение использует протокол AnkiConnect 6 и проверяет поля и шаблоны своих типов. При конфликте существующий тип не перезаписывается. Не удаляйте чужие типы или карточки только ради устранения ошибки.

Одна заметка выбранного типа создаёт одну карточку. Автоматическая обратная карточка не добавляется; расписание повторений определяет Anki.

**При смене профиля Anki сначала разберитесь с незавершённой очередью.** Подключение идёт к открытому профилю, а не к профилю, привязанному к расширению навсегда. После переключения заново проверьте соединение, колоды и типы. Не отправляйте старые задания в другой профиль вслепую.

## Языки и направление перевода

В разделе **«3. Языки и уровень»** выберите **язык текста**, **язык перевода** и ориентировочный уровень **A1–C2**, затем сохраните настройки.

Доступны: английский, русский, испанский, французский, немецкий, итальянский, португальский, китайский, японский, корейский, арабский, хинди, турецкий, украинский, польский, нидерландский и казахский. Направление выбирается из этих языков; например, английский → русский или немецкий → английский. Одинаковые языки включают одноязычный режим объяснений и перефразирования.

- Китайский ориентирован на стандартный мандаринский и упрощённую письменность.
- Арабский ориентирован на современный литературный арабский (MSA), не на все региональные диалекты.
- Для английского доступны американское и британское произношение.
- CEFR используется как ориентир сложности дополнительных примеров, а не как сертифицированная оценка текста или уровня пользователя.
- Качество всех направлений не измерено. Перевод, определение, начальную форму и примеры нужно проверять.
- Для китайского и японского лимит выделения считается по лексическим сегментам браузера, а не по пробелам. При отказе попробуйте более короткое выражение.

Новые настройки применяются к следующему переводу. Уже открытая карточка и задания очереди сохраняют исходные языки, колоду и другие параметры.

## Работа со словами и карточками

### Перевести слово или выражение

1. На обычном сайте нажмите значок расширения → **«Включить чтение»**. В собственной библиотеке расширения отдельная активация не требуется.
2. Наведите курсор на слово либо вручную выделите выражение до пяти лексических сегментов.
3. Нажмите **Shift**. Если есть ручное выделение, оно важнее слова под курсором.
4. Дождитесь результата, сверьте показанную цитату и выберите значение, подходящее к исходному предложению. Если контекст неоднозначен, выбор требует вашего внимания. Не сохраняйте карточку, если в показанном фрагменте отсутствует важная часть контекста.

В окне перевода показывается извлечённый исходный контекст. Перенос строки внутри абзаца сам по себе не завершает предложение; границы отдельных блоков сохраняются. Очень длинный словарный контекст ограничивается 1500 единицами UTF-16 вокруг выделения, поэтому это может быть фрагмент предложения. Проверяйте контекст перед сохранением.

HTML-режим работает с доступным текстом обычной веб-страницы. Системные страницы Chrome, Chrome Web Store, страницы других расширений, `file://` и встроенный PDF-просмотрщик не подходят для этого режима. Для книг используйте библиотеку. Импорт через выбор файла не требует разрешения Chrome «Разрешить доступ к URL файлов».

Повторное нажатие Shift для нового фрагмента открывает новый перевод. Несохранённые изменения старого черновика не переносятся в него. Закрытие окна не отменяет уже отправленное сохранение в Anki и не гарантирует отмену расходов провайдера.

### Начальная форма и фразовые глаголы

Если модель уверенно вернула глагол и его лемму, под исходной формой появляется **«Инфинитив»** или **«Начальная форма»**, например `kept` → `keep`. Строка может отсутствовать для неоднозначного разбора, неизвестной части речи или неподходящих данных. Это сведения модели, не независимая морфологическая проверка. Исходная цитата при этом не заменяется инфинитивом.

Для английского без ручного выделения локальный набор из **40 семейств глаголов** предлагает варианты соседних сочетаний, например `kept up` или `went by`. Тот же запрос перевода выбирает выражение по контексту; отдельного платного запроса «распознать фразовый глагол» нет.

Набор не исчерпывает английские фразовые глаголы. Автоматическое расширение касается **непрерывного** фрагмента. Разделённое `turn it off` не превращается в выдуманное исходное `turn off`: выделите всё выражение вручную. В спорном случае проверьте результат или выберите нужный фрагмент сами.

### Подготовить заметку

- **Значения.** В карточку попадают все значения текущего ответа, максимум восемь с максимум четырьмя переводами на каждое. Выбранное значение идёт первым. Это подборка распространённых значений, не полный словарь.
- **Редактирование.** Можно изменить переводы выбранного значения, его определение и лемму. Исходное предложение и точное выделенное вхождение сохраняются.
- **Узнавание.** Вопрос показывает выражение в исходном контексте; ответ содержит значения и дополнительные сведения.
- **Пропуск (c1).** Скрывается точное выбранное вхождение, а не все одинаковые слова в предложении. Ответ раскрывается на обороте.
- **Предпросмотр.** Перед отправкой проверьте вопрос и ответ кнопкой **«Предпросмотр»**.
- **Дополнительные примеры.** В **«Дополнительных действиях»** нажмите **«Получить до 3 примеров — платный запрос»** и отметьте только нужные. Они относятся к выбранному значению, помечаются как созданные ИИ и не заменяют цитату из книги.
- **Уточнение.** **«Уточнить смысл — платный запрос»** выполняет отдельный запрос. Это не гарантированное исправление всех ошибок.

На странице сайта колода выбирается через **«Выбрать колоду в настройках»**. Её список и имя не выводятся в окно на чужом сайте. В доверенной библиотеке доступен выбор колоды прямо в карточке.

Нажмите **«Добавить в Anki»**. После отправки снимок карточки фиксируется: повтор сохранения относится к той же операции, а не незаметно изменённой заметке. Для другого содержимого нужно новое намеренное сохранение; сначала выясните итог прежнего.

### Произношение и аудио

Транскрипция показывает источник: **«словарь»** или **«сгенерировано ИИ»**. Приблизительная IPA не становится словарно подтверждённой из-за квадратных скобок. Для некоторых слов и языков транскрипция может быть недоступна.

- **Системное прослушивание:** кнопка ▶ использует подходящий локальный голос, если он установлен. Это не платный OpenAI TTS и не аудиофайл для Anki. Другим языком отсутствующий голос не подменяется.
- **Словарная IPA:** необязательный `dictionaryapi.dev` включается отдельно и получает английское слово. Для других языков этот словарь не вызывается.
- **Файл для Anki:** сначала разрешите платное облачное аудио в настройках. Затем в карточке отметьте **«Создать аудиофайл (платный запрос)»**. Именно включение флажка запускает запрос, а не последующее добавление заметки.

Дождитесь готовности, прослушайте файл и сохраните карточку. В Anki передаётся уже подготовленный файл без повторной генерации ради сохранения. Флажок изначально выключен. Изменение значения или важных полей может сделать прежнее аудио неподходящим; нельзя незаметно прикрепить его к другому содержимому. Если после правок аудио недоступно, следуйте подсказке интерфейса или сохраните без него. Снятие флажка после отправки запроса не отменяет уже возникший расход.

## Очередь и повтор сохранения

Откройте значок расширения → **«Очередь Anki»**.

| Статус | Что это означает |
| --- | --- |
| «Ожидает отправки — не добавлено» / «Готово к отправке — не добавлено» | Снимок сохранён локально, но добавление в Anki ещё не подтверждено |
| «Отправляется» / «Проверяем результат отправки» | Запрос выполняется или его результат уточняется; не создавайте вторую операцию |
| «Добавлено в Anki» | Добавление подтверждено; можно открыть заметку |
| «Нужно проверить дубликаты» | Решите, нужна ли новая заметка несмотря на похожую |
| «Ошибка аудио — требуется решение» | Повторить подготовку, явно отправить без аудио или отменить локальную операцию |
| «Не удалось отправить» | Прочитайте ошибку, восстановите условия и используйте повтор именно этого задания |

При временной недоступности Anki очередь может выполнять ограниченные фоновые повторы, пока браузер работает. Это не обещание отправки при закрытом Chrome. Повтор очереди использует сохранённый перевод и параметры, а не генерирует их заново по текущим настройкам.

**Неизвестный результат не равен неуспеху.** После тайм-аута заметка могла попасть в Anki. Сначала проверьте исходную операцию и коллекцию, не создавайте новую карточку «на всякий случай». Техническая сверка операции и проверка похожих учебных карточек — разные проверки; отсутствие найденного дубликата не заменяет подтверждения отправки.

Отмена в очереди отменяет локальное намерение отправить заметку. Она не удаляет уже созданную карточку или её медиа из Anki. Во время отправки и сверки часть действий специально недоступна.

## Грамматические карточки

Грамматика отмечена как **экспериментальная** и **выключена по умолчанию**. Разрешение на словарный перевод не включает её автоматически.

### Подготовка

1. В настройках откройте **«5. Грамматика (эксперимент)»**.
2. Разрешите платный разбор, выберите **«Язык объяснения грамматики»** и при необходимости подробное объяснение.
3. Укажите существующую отдельную колоду или оставьте поле пустым: тогда используется основная. Для новой колоды сначала создайте её в Anki.
4. Отдельно подтвердите подготовку типа и нажмите **«Подготовить тип грамматики»**.
5. Нажмите **«Сохранить настройки»**.

Совместимый `LanguageReader.Grammar.v1` используется без изменений. Если его нет или он несовместим, подтверждённая подготовка может создать отдельный `LanguageReader.Grammar.v2`. Конфликтующие типы и существующие карточки не переименовываются, не удаляются и не переписываются. Конфликт самого v2 требует разбора, а не ещё одной автоматической замены.

### Использование

- После включения функции наведите курсор на предложение и **нажмите и отпустите левый Alt без других клавиш**. Это явное действие генерации и может быть платным.
- Либо откройте **«Грамматика предложения»** в дополнительных действиях перевода и нажмите **«Создать карточку»**. Само открытие окна кнопкой запрос не отправляет.
- AltGr, сочетания клавиш, ввод в полях и IME не должны запускать разбор. Поведение системных клавиш зависит также от ОС и браузера.
- Сверьте показанный исходный текст: он должен содержать нужную часть предложения. Проверьте вопрос, ответ, правило, перевод и необязательное объяснение. Текстовые пояснения можно исправить до отправки; **исходный фрагмент не перефразируется**.
- Нажмите **«Предпросмотр»**, затем **«Добавить в Anki»**.

Разбор выбирает одну конструкцию и один полезный вопрос. Язык объяснения задаётся отдельно от языка перевода предложения. У грамматики нет аудио, режима cloze, автоматического добавления и фоновой очереди отправки. Не закрывайте её окно с незавершённой операцией в расчёте на обычную словарную очередь.

### Если тип грамматики несовместим

1. В том же черновике нажмите **«Настроить тип грамматики»**.
2. В настройках, раздел «Грамматика», подтвердите создание совместимого отдельного типа и нажмите **«Подготовить тип грамматики»**.
3. Вернитесь к **прежнему открытому черновику** и нажмите **«Проверить после настройки»**. Новая генерация не нужна.

При ошибке связи кнопка может называться **«Проверить и повторить»**, а при неопределённом результате — **«Проверить результат»**. Снимок и идентификатор операции сохраняются. Сначала выполняется сверка Anki; неизвестный исход не разрешает слепую повторную отправку. Если конфликт остался, проверьте типы и последние заметки в Anki, не удаляя их автоматически.

## Книги и локальная библиотека

Откройте **«Библиотеку»**, нажмите **«Открыть книгу»** или перетащите один файл. Импорт сохраняет книгу в хранилище этого расширения и профиля браузера, а не на сервере разработчика.

| Формат | Возможности и ограничения |
| --- | --- |
| **PDF**, до 100 МиБ | Собственный просмотрщик PDF.js, реальные страницы документа, переход по номеру, масштаб и «По ширине». Для выделения и поиска нужен текстовый слой. OCR сканов нет |
| **EPUB**, до 100 МиБ | EPUB 2/3 с перетекающим текстом, без DRM и fixed-layout. Оглавление, разделы, сохранение позиции по CFI, изменение шрифта и ширины |
| **FB2**, до 16 МиБ | Обычный `.fb2`: UTF-8, Windows-1251 или UTF-16 с BOM. Разделы и перетекающий текст. `.fb2.zip` не поддерживается; встроенные изображения и бинарные вложения не отображаются |

Повреждённые, чрезмерно сложные файлы и архивы, превышающие внутренние ограничения, могут быть отклонены даже в пределах максимального размера. EPUB и FB2 обрабатываются с ограничениями: скрипты, формы, внешние ресурсы и часть оформления книги не поддерживаются. Поэтому вид может отличаться от другой читалки. Снятие ограничений не является способом открыть неподдерживаемую книгу.

### Продолжение чтения и оформление

- Библиотека показывает книги и сохранённое место. Кнопка **«Продолжить чтение»** возвращает к последней книге.
- Для PDF сохраняются страница и положение; для EPUB/FB2 — позиция в тексте и раздел. У перетекающей книги нет постоянного номера печатной страницы.
- В EPUB/FB2 доступны размер шрифта, ширина, межстрочный интервал и светлая/тёмная тема. Число экранов внутри раздела зависит от окна и оформления.
- Закладки можно назвать, открыть или удалить. Закладки и оформление хранятся отдельно для каждой локально сохранённой книги.
- При недостатке места или невозможности сохранения может быть предложено **«Открыть только на текущую сессию»**. В этом режиме книга, новое место, закладки и оформление не сохраняются после закрытия.

### Поиск

Поиск по книге запускается вручную и работает локально, без OpenAI. Он ограничен объёмом обрабатываемого текста и числом результатов. Если просмотрена только часть книги, интерфейс сообщает об этом: пустой частичный поиск не доказывает отсутствие слова во всём документе. Поиск не выполняет OCR и не переписывает исходный текст ради подсветки.

Храните оригиналы книг отдельно. Локальная ссылка на источник и позицию может не открыться на другом устройстве; библиотека не синхронизируется через Anki.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| **Shift** | Перевести ручное выделение или слово под курсором |
| **Левый Alt: нажатие и отпускание** | Разобрать предложение, только после отдельного включения грамматики |
| **Enter** | Добавить словарную карточку, когда фокус не находится в редактируемом поле или другом управляющем элементе |
| **Ctrl+Enter** | Сохранить словарную карточку из режима редактирования |
| **Escape** | Закрыть окно перевода |
| **Tab / Shift+Tab** | Обычная навигация по элементам интерфейса |
| **← / → / Page Up / Page Down** | Листать активную книгу в библиотеке |

Для перелистывания книги не требуется предварительно нажимать на текст. Оно не должно перехватывать ввод в поиске и других полях, работу с кнопками и списками, IME, выделенный текст и управление открытым переводом. Отпускание Shift само по себе не закрывает перевод.

## Если что-то не работает

| Симптом | Что сделать |
| --- | --- |
| Расширение не загружается | Проверьте Node 24+, успешность `npm ci` и сборки. Выберите папку результата с `manifest.json`, не ZIP исходников |
| Shift ничего не делает | На обычном сайте нажмите «Включить чтение», после обновления перезагрузите вкладку; наведите курсор на текст, выйдите из поля ввода. Служебные страницы и встроенный PDF-просмотрщик не поддерживаются |
| Длинное выражение не принимается | Сократите выделение до пяти лексических сегментов. Для разделённого фразового глагола выберите точный фрагмент вручную |
| `OPENAI_AUTH` / `MODEL_UNAVAILABLE` | Проверьте ключ в настройках, его разрешения и доступ к `gpt-6-luna`. После завершения сессии ключ мог исчезнуть. Автоматической подмены модели нет |
| `OPENAI_QUOTA` / `OPENAI_RATE_LIMIT` | Проверьте API-баланс, лимиты проекта и модели. Если используете промокредиты, проверьте их срок действия и что ключ относится к привязанной организации. При ограничении частоты подождите перед новым действием |
| `OPENAI_REQUEST_REJECTED` | Провайдер отклонил параметры запроса, это не ошибка разбора готового ответа. Повтор с теми же параметрами не предлагается. Откройте «Технические сведения» и сохраните «Код» и «Диагностика» для отчёта; проверьте версию расширения и доступ к модели |
| `INVALID_MODEL_OUTPUT` / `MODEL_INCOMPLETE` | Ответ не прошёл проверку или не был завершён. Проверьте показанное направление перевода, исходный фрагмент и кнопку «Проверить языки в настройках». «Повторить перевод», если доступно, отправляет новый, возможно платный запрос. При повторяющемся сбое сохраните безопасные код и диагностику, а не необработанный ответ |
| Anki недоступен | Убедитесь, что запущен Anki Desktop, установлен AnkiConnect, после установки был перезапуск, открыт нужный профиль и выбран локальный адрес. Общая сетевая ошибка сама по себе не доказывает конкретную причину |
| `ANKI_AUTH` / `ANKI_ORIGIN_DENIED` | Проверьте отдельный ключ AnkiConnect и точный origin расширения. Не заменяйте разрешения на `*` |
| `ANKI_DECK_NOT_FOUND` | Заново получите колоды, выберите существующую или явно создайте её. Проверьте, не переключили ли профиль Anki |
| `ANKI_SCHEMA_MISMATCH` у словарной карточки | Проверьте совместимость AnkiConnect и собственных типов v2. Не перезаписывайте вручную чужую модель без понимания последствий; сохраните резервную копию |
| Ошибка типа у грамматики | Используйте «Настроить тип грамматики» → «Подготовить тип грамматики», затем «Проверить после настройки» в прежнем черновике |
| Карточка в очереди, но её нет в Anki | Очередь не означает успешную отправку. Прочитайте состояние, восстановите связь и работайте с исходной операцией, а не новой копией |
| Отправка зависла или результат неизвестен | Проверьте последние заметки и исходный профиль Anki. Не очищайте очередь и не повторяйте добавление новой операцией вслепую |
| Нет транскрипции или звука | Проверьте язык/диалект, наличие соответствующего локального голоса и отдельные разрешения словаря/облачного аудио. Отсутствие IPA не обязательно блокирует перевод |
| Книга не открывается | Проверьте формат, размер, отсутствие DRM/fixed-layout, для FB2 — отсутствие ZIP-обёртки. Для PDF-скана нужен заранее созданный текстовый слой |
| Прогресс или закладки не сохранились | Проверьте предупреждение о сессионном режиме, свободное место и ошибку хранения. При доступной кнопке повторите сохранение; оригинал книги не удаляйте |
| После обновления виден старый интерфейс | Обновите расширение на `chrome://extensions`, перезагрузите читаемые вкладки и снова откройте библиотеку |

Для воспроизводимого отчёта укажите версию расширения, Chrome и Anki, формат книги или тип страницы, последовательность действий, ожидаемый результат, показанную языковую пару, безопасные «Код» и «Диагностика» из «Технических сведений». Эти сведения обозначают этап и категорию сбоя, а не доказывают единственную причину. Приложите короткий неперсональный пример текста, если можете. **Не прикладывайте API-ключи, личные книги, коллекцию Anki, необработанные HAR или логи с Authorization.**

## Зачем расширению разрешения

Манифест не запрашивает постоянный доступ ко всем сайтам.

| Разрешение | Назначение |
| --- | --- |
| `activeTab`, `scripting` | Включить чтение и окно перевода в выбранной вкладке по вашему действию |
| `storage` | Сохранить настройки и служебное состояние; ключи по умолчанию сессионные |
| `alarms` | Обслуживать очередь и ограниченные фоновые повторы |
| `offscreen` | Фоновые операции, которым нужен документ браузера |
| `contextMenus` | Команды расширения в контекстном меню |
| `api.openai.com` | Запросы перевода, примеров, грамматики и облачного аудио |
| `127.0.0.1`, `localhost` | Связь с вашим локальным AnkiConnect; приложение ограничивает рабочее подключение портом 8765 |
| `api.dictionaryapi.dev` (необязательное) | Словарная английская транскрипция после отдельного разрешения |

## Приватность и хранение данных

В проекте нет собственного сервера разработчика для хранения книг или обработки переводов. Книги, настройки, кэш, прогресс, закладки и очередь хранятся локально в профиле браузера. Это не означает, что все функции работают офлайн:

- **OpenAI:** по действию генерации получает выбранное выражение, исходное предложение и ограниченный окружающий контекст, языки, уровень и параметры запроса. Словарный контекст ограничен 1500 единицами UTF-16. Уточнение и примеры используют относящиеся к ним данные; грамматика отправляет исходное предложение. Вся книга не загружается. Облачное аудио отправляет необходимые для озвучивания текст и параметры.
- **dictionaryapi.dev:** только после разрешения получает английское слово для транскрипции.
- **Локальный AnkiConnect:** получает подтверждённые поля заметки, сведения об источнике и, если выбрано, подготовленное аудио. Если у вас включена синхронизация Anki, последующая синхронизация этих данных управляется Anki.

Источник сайта не подставляется целиком в модельный запрос. При экспорте в Anki URL очищается от query и fragment; локальные пути файлов не используются как публичный источник. Это не повод отправлять конфиденциальный текст: провайдер всё равно получает фрагмент, который вы просите обработать.

Кэш и очередь могут содержать прочитанные предложения. Удаление расширения или данных профиля может удалить локальную библиотеку и незавершённые операции. Подробнее: [приватность](docs/PRIVACY.md) и [аудио](docs/PRIVACY_AUDIO.md); старые документы могут описывать предыдущие этапы реализации.

## Обновление и резервные копии

1. Сделайте резервную копию коллекции Anki, включая медиа, и сохраните исходники книг вне браузера.
2. Проверьте очередь. Разберитесь с неизвестными исходами отправки до смены профиля, адреса или удаления расширения.
3. Соберите новую версию и замените файлы **в той же постоянной папке** установленного расширения.
4. На `chrome://extensions` нажмите обновление/перезагрузку Language Reader.
5. Перезагрузите вкладки чтения, заново откройте страницы расширения и при необходимости введите сессионные ключи.

Не удаляйте расширение и не очищайте его данные ради обычного обновления. Загрузка из другой папки может создать отдельное расширение с другим ID и хранилищем; тогда изменится и origin для AnkiConnect. Очередь не заменяет резервную копию Anki, а встроенный экспорт всей библиотеки и очереди в этой версии не заявлен.

Старые заметки `EnglishReader` и новые `LanguageReader` автоматически не преобразуются. Если сохранённая старая очередь требует отсутствующих типов v1, в настройках есть отдельный раздел **«Восстановление типов v1 для старой очереди»** и отдельное согласие. Это не обновление существующих карточек и не разрешение отправить всю очередь без проверки.

## English quick start

**Language Reader for Anki** is a desktop Chrome extension for contextual vocabulary lookup while reading websites, PDF, reflowable EPUB and plain FB2 books. The interface is currently Russian. You bring your own OpenAI API key and a local Anki Desktop installation with AnkiConnect.

1. Install Node.js 24+ and download or clone this repository. Run these commands from the folder containing `package.json`:

   ```sh
   npm ci
   npm run build
   ```

2. Open `chrome://extensions`, enable **Developer mode**, select **Load unpacked**, and choose `dist/english-reader/`. The source ZIP is not an installable extension. The build also creates `dist/english-reader.zip` for local distribution; extract it before loading.
3. Open the extension settings (**Настройки**). Save your own OpenAI API key. API billing is separate from ChatGPT. If eligible, you can use [activated API credits](https://help.openai.com/en/articles/20001626-api-credits-benefit-for-eligible-chatgpt-subscriptions) with a project key from the linked API organization. Session-only key storage is the default; persistent local storage is optional and is not an encrypted vault.
4. Install AnkiConnect (add-on code `2055492159`) in Anki Desktop and restart Anki. Keep Anki running. Use `http://127.0.0.1:8765`. If CORS blocks the connection, add only your exact `chrome-extension://YOUR_EXTENSION_ID` origin to AnkiConnect's `webCorsOriginList`. Do not expose the service to the internet or allow all origins.
5. In the extension settings, check the connection, choose a deck and explicitly prepare the extension's note types. A missing deck must be created explicitly. If AnkiConnect has an API key, enter that separate key too.
6. On a website, click **Включить чтение** in the extension menu. Hover over a word or select a short expression and press **Shift**. Check the selected meaning, preview the note, then choose **Добавить в Anki**. For books, import a file through **Библиотека**.

Version 0.7.6 adds English-only CEFR, contemporary usage and qualitative frequency estimates to the lookup popup, plus a temporary Shift reading marker that remains after closing the popup, but is not a saved bookmark. Estimates arrive in the same lookup response, without a separate request. These estimates are model-generated, not authoritative corpus statistics, and **are not exported to Anki**. The reader supports 17 source/translation languages, but quality has not been benchmarked for every pair.

Books and reading state remain local. Explicit model requests send the selected text and relevant limited context to OpenAI; the optional pronunciation service receives the English word. Never submit confidential material without considering the provider's data handling. Back up your Anki collection and keep original book files separately.
