4. ПОВЕДЕНИЕ ПРИ ЧТЕНИИ
==================================================

Движение мыши:
- обновляет координаты;
- не выполняет API-запросов.

Нажатие Shift:
- использует выделение до пяти слов в активном документе, если оно есть;
- иначе определяет слово под курсором;
- игнорирует key repeat;
- открывает компактное окно.

Не активируй перевод:
- в input, textarea, contenteditable;
- в полях пароля;
- во время IME composition;
- вместе с Ctrl, Alt или Meta;
- при синтетическом событии, которое не является действием пользователя.

Отпускание Shift не закрывает окно.
Escape и клик вне окна закрывают его.

Режим сканирования при удержании Shift — отдельная настройка, выключенная по умолчанию. Если реализуешь его, обязательны стабилизация курсора, дедупликация, ограничение частоты и отмена устаревших запросов.

HTML:
- используй DOM Range, доступные caret API и сегментацию;
- не оборачивай заранее каждое слово страницы;
- учитывай апострофы, дефисы, пунктуацию и слова на границах текстовых узлов;
- не обещай доступ к закрытым shadow roots, системным страницам Chrome и недоступным frame;
- при ограничениях показывай понятный статус.

Контекст:
- сохраняй исходное предложение;
- при необходимости добавляй по одному соседнему;
- суммарный предел отправляемого контекста — 1500 UTF-16 code units;
- сохраняй точный диапазон [targetStart, targetEnd);
- диапазон относится к неизменённой строке sentence;
- sentence.slice(targetStart, targetEnd) должно совпадать с expression;
- нормализацию для кэша выполняй отдельно от оригинала.

Не отправляй модели:
- весь документ;
- URL с токенами;
- имя пользователя Windows;
- локальный путь;
- название книги, если оно не нужно для перевода.

5. POPUP И УЧЕБНЫЙ UX
==================================================

Порядок элементов:
1. Expression, часть речи, кнопка прослушивания.
2. IPA и обозначение источника или отсутствия данных.
3. Основной перевод для текущего контекста.
4. Исходное предложение с выделением.
5. Свёрнутые альтернативные значения.
6. Свёрнутое краткое английское определение.
7. Дополнительный пример, только если запрошен.
8. Добавить в Anki, Редактировать, дополнительные действия.
9. Колода, тип заметки, состояние аудио и сохранения.

Правила:
- одно выбранное значение на заметку;
- один-два перевода этого же значения;
- не помещать все значения слова в одну карточку;
- исходное предложение не переписывается моделью;
- дополнительный пример помечается как созданный ИИ;
- основное сохранение не требует дополнительного запроса к текстовой модели;
- уровень дополнительных объяснений по умолчанию B1;
- диалект по умолчанию en-US.

Горячие клавиши при открытом окне:
- Enter — добавить, если пользователь не редактирует поле;
- Escape — закрыть;
- Tab — обычная навигация;
- Ctrl+Enter — сохранить из режима редактирования.

Окно:
- Shadow DOM для изоляции стилей;
- Shadow DOM не считать границей безопасности;
- положение внутри viewport;
- по возможности не перекрывать исходное предложение;
- светлая и тёмная темы;
- доступные подписи, фокус и контраст;
- масштабируемый текст;
- не модальное, без ловушки фокуса;
- при прокрутке обновлять положение;
- скрывать незакреплённое окно, если anchor ушёл с экрана.

Обязательные состояния:
loading, result, ambiguous, error, audio_loading,
saving, queued, added, duplicate_review, already_added.

Старый ответ никогда не заменяет результат более нового запроса.

«Добавлено в Anki» и «Сохранено в очередь» — разные сообщения.
Если транскрипция сгенерирована, показывай «≈ / сгенерировано ИИ», а не «проверено».

6. PDF, EPUB И ЛОКАЛЬНАЯ БИБЛИОТЕКА
==================================================

PDF:
- собственный viewer на локально упакованном PDF.js;
- не рассчитывай на внедрение во встроенный PDF-viewer Chrome;
- добавить действие «Открыть в English Reader»;
- поддержать выбор файла и drag-and-drop;
- использовать текстовый слой;
- лениво отображать страницы;
- сохранять страницу и положение;
- отключить выполнение PDF JavaScript и автоматические внешние действия;
- PDF.js worker, шрифты и необходимые ресурсы включить в сборку.

Если текстового слоя нет, явно сообщить, что OCR не поддерживается.
При плохом извлечении предложить выделение или исправление текста.

EPUB:
- использовать локально упакованный epub.js;
- EPUB 2/3, reflowable, без DRM;
- локальный импорт обязателен;
- оглавление, предыдущая/следующая глава;
- настройка размера шрифта, ширины чтения, межстрочного интервала и темы;
- восстанавливать позицию по EPUB CFI;
- сохранять главу и CFI как источник заметки;
- не придумывать постоянные номера страниц для reflowable EPUB.

Содержимое EPUB — недоверенное:
- рендерить внутри sandboxed iframe без allow-scripts;
- allow-same-origin допустим только для управляемого доступа родителя к DOM;
- обработчики чтения и выделения устанавливает код расширения из родительского контекста;
- не выполнять скрипты книги;
- удалить inline handlers, формы, вложенные iframe, object/embed, meta refresh;
- не разрешать top navigation;
- не загружать внешние изображения, CSS, шрифты и другие ресурсы автоматически;
- переписывать допустимые внутренние ресурсы на контролируемые локальные URL;
- очищать HTML, SVG и CSS;
- внешние ссылки открывать только после явного действия пользователя;
- не ослаблять sandbox ради совместимости.

Защита ZIP:
- максимум 100 MiB архив;
- максимум 500 MiB суммарно распакованных данных;
- максимум 50 MiB один файл;
- максимум 10000 записей;
- ограничение коэффициента распаковки 200:1;
- проверять фактический объём при распаковке;
- отклонять path traversal, абсолютные пути, конфликтующие имена;
- тяжёлую обработку выполнять в worker;
- не распаковывать вложенные архивы рекурсивно.

Не считай любое encryption.xml доказательством DRM:
стандартная обфускация шрифтов отличается от шифрования книги. Если такие шрифты не поддержаны, используй системный шрифт. Защищённый текст не расшифровывай.

Библиотека:
- импорт означает явное локальное сохранение книги в браузере;
- хранить книгу и прогресс через общий storage-слой dot b;
- documentId — локальный отпечаток файла;
- контролировать quota;
- не удалять книги и очередь при обычной очистке кэша;
- при нехватке места предложить открыть файл только на текущую сессию;
- не отправлять файлы в облако;
- не передавать большие файлы base64 через runtime.sendMessage.

В источнике заметки:
- HTML: заголовок и безопасный URL;
- PDF: имя/название и страница;
- EPUB: название, глава и CFI.
Не обещай работоспособность локального источника на другом устройстве.

7. ANKI И СОБСТВЕННЫЕ ТИПЫ ЗАМЕТОК
==================================================

Типы:
- EnglishReader.Recognition.v1
- EnglishReader.Cloze.v1

Recognition:
- лицевая сторона: expression и исходное предложение;
- обратная: выбранный перевод, определение, IPA, аудио, дополнительный пример, источник.

Cloze:
- один пропуск c1;
- скрывать только выбранное вхождение;
- на лицевой стороне не показывать ответ и не проигрывать аудио ответа;
- обратная сторона содержит полное предложение и пояснения.

Один выбранный тип создаёт одну карточку.
Не создавать reverse автоматически.
Не менять расписание Anki.

Поля:
OperationId, LexemeKey, ContentKey, Expression, Lemma,
PartOfSpeech, Meaning, DefinitionEN, Sentence, ClozeSentence,
IPA, IPASource, Audio, ExtraExample, ExtraExampleTranslation,
SourceTitle, SourceURL, SourceLocation.

OperationId — первое техническое поле.

При первом запуске:
- объяснить необходимость Anki и AnkiConnect;
- проверить соединение;
- предложить выбрать колоду;
- предложить English::Reading, но не создавать молча;
- запросить согласие на создание собственных типов заметок;
- при конфликте существующей схемы не менять её автоматически.

Предпросмотр должен использовать тот же рендеринг данных, что и итоговая заметка, а не отдельную несовместимую реализацию.

9. БАЗОВЫЙ RPC-КОНТРАКТ
==================================================

Транспорт: Chrome runtime messaging.
Version: v=1.

Request:
{v:1, requestId:UUID, type:string, payload:object}

Success:
{v:1, requestId:UUID, ok:true, data:object, warnings:string[], meta?:object}

Error:
{v:1, requestId:UUID, ok:false,
 error:{code:string, message:string, retryable:boolean}}

lookup.payload:
{
 expression:string,
 context:{
   sentence:string,
   targetStart:integer,
   targetEnd:integer,
   before?:string,
   after?:string
 },
 sourceLanguage:"en",
 targetLanguage:"ru",
 learnerLevel:"B1",
 dialect:"en-US"|"en-GB"
}

lookup.data:
{
 lookupId:string,
 expression:string,
 lemma:string,
 partOfSpeech:string,
 recommendedSenseId:string|null,
 contextAmbiguous:boolean,
 senses:[
   {id:string, translations:string[], definitionEn:string}
 ],
 ipaCandidate:null|{ipa:string,dialect:string},
 extraExample:null|{textEn:string,textRu:string,source:"ai"}
}

Смыслов 1–4. Переводов на смысл 1–3.
ipaCandidate никогда не означает проверенную транскрипцию.

NoteDraft:
{
 sourceLanguage:"en",
 targetLanguage:"ru",
 mode:"recognition"|"cloze",
 deckName:string,
 tags:string[],
 expression:string,
 lemma:string,
 partOfSpeech:string,
 selectedSense:{
   id:string,
   translations:string[],
   definitionEn:string
 },
 context:{
   sentence:string,
   targetStart:integer,
   targetEnd:integer
 },
 pronunciation:{
   ipa:string|null,
   dialect:"en-US"|"en-GB"|"unknown",
   source:"dictionary"|"generated"|"unavailable",
   sourceUrl:string|null
 },
 extraExample:null|{textEn:string,textRu:string,source:"ai"},
 source:{
   kind:"html"|"pdf"|"epub",
   title:string,
   url:string|null,
   documentId:string|null,
   page:integer|null,
   chapter:string|null,
   cfi:string|null
 }
}

В NoteDraft selectedSense.translations содержит 1–2 перевода одного значения.
Для PDF page начинается с 1. Для EPUB используются chapter и cfi.

Секретные и административные операции разрешены только доверенным страницам расширения.

anki.addNote.payload:
{
 operationId:UUID,
 draft:NoteDraft,
 includeAudio:boolean,
 audioId?:string,
 duplicateAction:"review"|"add_new"
}

anki.addNote.data:
{
 operationId:UUID,
 status:"added"|"queued"|"already_added"|"duplicate_review",

}

duplicateAction по умолчанию review.
add_new допустим только после явного подтверждения пользователя.

Для обновления UI согласовать событие operation.updated:
operationId, state, noteId, error.
После восстановления соединения UI перечитывает очередь: события не являются долговременным хранилищем.

Полные схемы, enums, пределы строк и коды ошибок создаёт dot b и согласует с тобой. Не создавайте второй несовместимый набор типов в UI.

10. ПРОИЗНОШЕНИЕ, СТОИМОСТЬ И ПРИВАТНОСТЬ
==================================================

Основной перевод — gpt-4.1-mini.
«Уточнить смысл» — gpt-4.1, с понятным предупреждением о платном запросе.
Не повышать модель автоматически.

Для быстрого бесплатного прослушивания использовать доступный локальный системный голос.
Не обещать наличие такого голоса на любой Windows.
Не считать speechSynthesis источником экспортируемого файла.

Облачное аудио выключено до согласия.
При его включении файл создаётся по явному действию или при сохранении заметки.
Ошибка аудио не должна незаметно превращаться в сообщение «аудио добавлено».

Словарный источник IPA — необязательный dictionaryapi.dev.
Его сетевое использование явно раскрывается и включается с согласием.
Недоступность словаря не блокирует перевод.

Локальный кэш имеет прикладной лимит 100 MiB.
Очередь, библиотека и необходимые для отправки медиа не удаляются LRU-очисткой кэша.

Не включать внешнюю аналитику.
В интерфейсе объяснить, что API OpenAI оплачивается отдельно от подписки ChatGPT.

11. ТЕСТЫ И КРИТЕРИИ ГОТОВНОСТИ
==================================================

Проверить:
- отсутствие API-запросов без действия пользователя;
- точный диапазон слова и выражения;
- апострофы, дефисы, несколько DOM-узлов;
- неактивацию в редактируемых полях;
- защиту от устаревшего ответа;
- Enter/Escape и управление фокусом;
- правильное значение bank в разных контекстах;
- put up with как выражение;
- несколько одинаковых слов в предложении;
- PDF с текстом и скан без текста;
- EPUB с главами и восстановлением CFI;
- изменение шрифта EPUB без потери места;
- блокировку скриптов и внешних запросов из EPUB;
- ограничение ZIP и path traversal;
- кириллицу и пробелы в именах файлов Windows;
- Add, двойной Add, очередь и восстановление браузера;
- отсутствие ключа в DOM, content scripts и логах;
- аудиофайл в настоящей заметке Anki.

Цели производительности, которые надо измерить, а не объявить выполненными:
- оболочка popup до 100 мс;
- кэшированный результат до 150 мс;
- некэшированный перевод: целевой p95 до 4 секунд в описанных условиях;
- ограниченный тайм-аут и отсутствие вечного loading.

Playwright/Chromium-тесты не выдавать за реальную проверку Windows Chrome.
Если среды Windows нет, подготовь сборку и точный smoke checklist, а Windows-проверку отметь not_run.

Платные live-тесты OpenAI запускаются только при наличии безопасно предоставленного ключа и явного opt-in.
Реальные тесты Anki — в отдельном тестовом профиле, не в личной коллекции владельца.
