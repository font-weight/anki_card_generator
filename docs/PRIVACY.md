# Приватность и границы доверия

Этот документ описывает предусмотренную модель данных. Проверенное покрытие и оставшиеся gates перечислены в `TEST_REPORT.md`; это не независимый security audit.

## Что может покидать устройство

| Получатель | Данные | Условие |
|---|---|---|
| OpenAI API | Выбранное английское слово/фраза и ограниченный контекст, язык/диалект/уровень; отдельно текст для TTS | Явный запрос пользователя, ключ в настройках; cloud audio отдельно opt-in |
| dictionaryapi.dev | Искомая лемма для IPA | Только после согласия на словарный сетевой источник |
| AnkiConnect на loopback | Поля выбранной заметки, технические ключи, выбранный источник и optional audio | Явное сохранение или повтор авторизованной очереди |

Не отправляются в модель целая книга/документ, локальный путь, Windows username, URL с токенами или ненужное название книги. Суммарный текст контекста ограничен 1500 UTF-16 code units. Источник заметки хранится локально и передаётся Anki, а не добавляется автоматически к модельному prompt. Поля заметки могут затем синхронизироваться средствами Anki, если пользователь настроил такую синхронизацию; это вне управления расширения.

Внешняя аналитика и собственный облачный аккаунт отсутствуют. Импорт PDF/EPUB означает локальное сохранение, не загрузку файла в облако. Сеть провайдеров обслуживает доверенный сервисный слой расширения, не страница.

## API-ключ

Ввод только в доверенной странице настроек расширения. По умолчанию `chrome.storage.session`; постоянное локальное хранение только с отдельным opt-in. Доступ хранилища должен быть `TRUSTED_CONTEXTS`. Ключ не включается в public settings, content script messages, sync, URL, логи, репозиторий, screenshots или диагностику. Постоянное хранение не описывается как шифрованное: доступ к профилю браузера/скомпрометированному устройству остаётся риском.

OpenAI API оплачивается отдельно от подписки ChatGPT. Уточнение через более дорогую модель и cloud TTS не должны включаться автоматически. Пользователь отвечает за доступность API и свои лимиты расходов.

## Локальные данные

- Настройки; ключ при выбранном режиме хранения.
- Кэш переводов/медиа с прикладным лимитом 100 MiB.
- Очередь заметок, OperationId, выбранный смысл, исходное предложение и необходимые медиа.
- Импортированные книги, локальный fingerprint documentId и прогресс (PDF page/scroll, EPUB CFI).

Обычная очистка кэша **не должна** удалять очередь, книги и медиа, необходимые для отправки. Удаление книги — отдельное действие. Очередь может содержать чувствительные предложения даже после закрытия исходной страницы. Uninstall или очистка данных профиля может удалить всё локальное состояние; не считать это резервной копией.

## Недоверенное содержимое

HTML страницы, EPUB/PDF, модельный вывод и строки полей Anki недоверенны. Shadow DOM изолирует стили, но не является security boundary. Content sender не имеет права менять секреты/настройки или создавать модели; проверка только `sender.id` недостаточна, поскольку content script тоже принадлежит расширению. Доверенные RPC должны проверять origin/URL страницы расширения и валидировать payload.

EPUB распаковывается с ограничениями в worker, с запретом traversal и конфликтующих имён. Скрипты, inline handlers, формы, nested frames, SVG и стили книги удаляются; raster images доступны через управляемые локальные URL. Reader iframe не получает `allow-scripts` или top-navigation. Внешние ссылки требуют явного действия; внешние ресурсы не должны загружаться автоматически. PDF JavaScript и автоматические внешние действия отключены.

## Диагностика и удаление

Перед передачей отчёта удалите API-key, Authorization headers, текст личных страниц и пути к файлам. Не прикладывайте HAR без проверки. Для отзыва ключа удалите его в настройках расширения и при необходимости отзовите у провайдера. Для полного удаления локальных данных сначала завершите/отмените очередь и сохраните исходные файлы книг; затем удалите расширение или его профильные данные. Экспорт очереди/книг не считается реализованным без соответствующей функции интерфейса.
